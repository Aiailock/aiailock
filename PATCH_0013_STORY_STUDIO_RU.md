# Патч 0013 — мобильная «Студия истории»

Патч совместим с уже загруженной перепиской. Миграция не удаляет сообщения,
фото, воспоминания, скриншоты, пользователей или настройки.

## Что добавлено

1. **Мобильная вкладка «Добавить».** Одна форма для записи, воспоминания,
   особого момента, главы, альбома, GIF и интерактивного сюрприза.
2. **Автосохранение черновика на телефоне.** Набранный текст и оформление не
   пропадут при случайном закрытии вкладки.
3. **Шесть готовых визуальных сценариев:** личный дневник, нежность, ночной
   разговор, письмо, праздник и тихий момент.
4. **Главы.** Их можно добавить из «Студии» или кнопкой `+` между элементами;
   в reader это большой кинематографичный переход.
5. **Шесть дизайнов даты:** строка, центр с линиями, лента, дневниковая запись,
   капсула и разнесённые дата/время.
6. **Полное управление датой:** слева/по центру/справа, отдельный шрифт,
   скрытие времени глобально или только у выбранного элемента.
7. **Альбомы до 12 скриншотов.** Три вида: карусель с листанием пальцем,
   стопка снимков и коллаж.
8. **Красивая авторская реакция на альбом:** эмодзи и короткая подпись автора.
9. **Реакции читателя.** На скриншотах и особых моментах она может нажать
   `❤`, `🥹`, `😊`, `✨`, `😂` или `💔`.
10. **Реакции в аналитике.** В Admin → «Чтение» видна последняя реакция и
    история реакций.
11. **GIF между страницами.** Можно загрузить `.gif` или вставить прямую
    интернет-ссылку.
12. **Свои фоновые картинки из интернета.** Для каждой сцены доступны ссылка,
    положение фокуса и сила затемнения без ручного JSON.
13. **Своя обложка.** В настройках можно задать фон обложки, вступительную и
    финальную фразы.
14. **Ритм сцены:** компактный, обычный или кинематографичный с большой паузой.
15. **Выравнивание текста** отдельно для каждой страницы.
16. **Исправление выхода текста за рамки.** Длинные ссылки, слова, подписи,
    заголовки, аудиоплеер и админские карточки теперь ограничены шириной экрана.
17. **Удобная кнопка «Добавить» на телефоне** всегда доступна снизу админки.
18. **Ускоренная загрузка.** Admin, React, анимации, Supabase и иконки собраны
    отдельными чанками; reader не загружает тяжёлую админку.
19. **Рабочий lint.** В репозитории отсутствовал конфиг ESLint; он добавлен и
    проверка теперь реально выполняется.

## Самый надёжный способ установки — через терминал

Перед началом скачай резервную копию текущего GitHub-репозитория:
**GitHub → Code → Download ZIP**.

### 1. Заменить код в GitHub

Распакуй архив патча. В GitHub нужно загрузить **содержимое папки проекта**, а
не сам ZIP. Не загружай `node_modules`, `dist`, `.env` и `.git`.

Если используешь Git на компьютере:

```bash
git add .
git commit -m "Add mobile Story Studio, chapters and screenshot albums"
git push origin main
```

После push Netlify начнёт сборку автоматически.

### 2. Применить миграцию Supabase

Открой терминал в корне проекта:

```bash
npx supabase@latest login
npx supabase@latest link --project-ref ТВОЙ_PROJECT_REF
npx supabase@latest db push
```

Команда применит только новый файл:

```text
supabase/migrations/0013_story_studio.sql
```

Существующие данные не удаляются.

### 3. Опубликовать новую Edge Function

```bash
npx supabase@latest functions deploy reader-reaction
```

В `supabase/config.toml` для неё уже указано `verify_jwt = false`. Это правильно:
функция сама проверяет закрытый reader-token. Не включай стандартный Verify JWT.

Если ранее не задавал отдельный секрет reader-токенов, сделай один раз:

```bash
npx supabase@latest secrets set READER_ACCESS_SECRET="ДЛИННАЯ_СЛУЧАЙНАЯ_СТРОКА"
```

### 4. Дождаться Netlify

Открой **Netlify → Deploys** и дождись `Published`. Новых переменных Netlify
не нужно. По-прежнему используются только:

```text
VITE_SUPABASE_URL
VITE_SUPABASE_ANON_KEY
```

Если сайт показывает старый интерфейс: **Trigger deploy → Clear cache and
deploy site**, затем обнови страницу с очисткой кэша.

## Установка без терминала

1. В GitHub загрузи изменённые файлы и папки через **Add file → Upload files**.
2. Открой **Supabase → SQL Editor → New query**.
3. Полностью скопируй содержимое
   `supabase/migrations/0013_story_studio.sql`, нажми **Run** один раз.
4. Открой **Supabase → Edge Functions → Deploy a new function → Via Editor**.
5. Имя функции: `reader-reaction`.
6. Вставь целиком `supabase/functions/reader-reaction/index.ts`.
7. Отключи **Verify JWT** и нажми **Deploy**. Файл самостоятельный, поэтому
   дополнительные `_shared`-файлы для него не требуются.
8. Дождись автоматической сборки Netlify.

## Проверка после установки

1. Открой `/admin/login` и войди.
2. На телефоне нажми нижнюю кнопку **«Добавить»**.
3. Создай тестовую главу и открой Preview.
4. Создай альбом из 2–3 скриншотов, выбери «Карусель» и проверь листание.
5. В «Оформлении» выбери другой дизайн даты и вставь тестовый фон по `https`.
6. Открой обычную reader-ссылку, оставь реакцию на альбоме.
7. Вернись в Admin → **Чтение** и нажми «Обновить» — реакция должна появиться.
8. Удали тестовые элементы в Admin → История.
