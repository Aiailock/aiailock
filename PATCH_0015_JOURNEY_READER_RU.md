# Глобальное обновление 0015 — Journey Reader

Это обновление превращает обычную длинную ленту в цельное путешествие. Существующие сообщения, фото, видео, аудио, воспоминания, скриншоты, главы, реакции, статистика и настройки сохраняются.

## Что добавлено и исправлено

1. Порядок в Admin → «История» теперь является главным порядком reader.
2. Перетаскивание больше не изменяет реальную дату сообщения или воспоминания.
3. Одинаковые дата и время больше не могут случайно поменять карточки местами.
4. Кнопки «выше/ниже», drag-and-drop и вставка через `+` используют один порядок.
5. При открытии появляется полноценный экран подготовки истории.
6. Загрузка показывает настоящий прогресс страниц и медиа, а не декоративный таймер.
7. До начала чтения загружаются все тексты, даты, главы и подписи.
8. Фото, скриншоты, стикеры и обложки заранее прогреваются в кэше браузера.
9. Ссылки на приватные медиа кэшируются и не запрашиваются повторно для одного открытия.
10. Ошибка загрузки больше не оставляет пустой тёмный экран — появилась кнопка повторной попытки.
11. Фон автоматически меняет атмосферу по времени сообщения: рассвет, день, закат, ночь.
12. Настроенные настроения сохраняют приоритет: романтика, грусть, память и другие зоны.
13. Цветовые переходы стали заметнее, но текст остаётся контрастным.
14. Добавлено восемь анимаций: снизу, растворение, слева, справа, приближение, туман, переворот и слова по очереди.
15. Анимацию можно выбрать для каждого элемента и массово применить в «Истории».
16. Добавлен интерактив «Вопрос» с двумя ответами.
17. Добавлен интерактив «Развилка» с разными посланиями после выбора.
18. Добавлена «Шкала чувств» от 1 до 10.
19. Добавлен момент «Стереть защитный слой» несколькими касаниями.
20. Добавлен ритуал «Загадать желание».
21. Добавлен момент «Собрать созвездие» из пяти звёзд.
22. Ответы и завершённые ритуалы запоминаются в браузере читателя.
23. Лёгкая вибрация телефона подтверждает касания, если устройство её поддерживает.
24. Внизу появилась «Карта путешествия» с прогрессом и текущей главой.
25. Из карты можно перейти к любой главе.
26. Появилась отдельная закладка на любимое место.
27. Добавлен переход к следующей главе и возврат к обложке.
28. Добавлено мягкое автоматическое чтение с кнопкой паузы.
29. Можно выбрать маленький, обычный или крупный текст.
30. Показывается примерное оставшееся время чтения.
31. На обложке появилась кнопка «Начать путешествие».
32. Сохранены поддержка узких телефонов и `prefers-reduced-motion`.

## Важно перед установкой

- Сделай резервную копию репозитория через **GitHub → Code → Download ZIP**.
- Желательно сделать backup базы в Supabase.
- Не загружай в GitHub `.env`, `.git`, `node_modules` и `dist`.
- Новых ключей или платных сервисов не требуется.
- Применяй обновление в порядке: **SQL → Edge Function → frontend**.

## Способ 1 — через Supabase CLI (рекомендуется)

Из корня распакованного проекта:

```bash
npx supabase@latest login
npx supabase@latest link --project-ref ТВОЙ_PROJECT_REF
npx supabase@latest db push
npx supabase@latest functions deploy public-timeline
npx supabase@latest functions deploy get-media-url
```

Последней должна примениться миграция:

```text
supabase/migrations/0015_journey_reader_order.sql
```

Она добавляет безопасный ключ `display_order`, переносит в него текущую последовательность, создаёт админ-функцию перестановки и обновляет закрытое reader-представление. Сообщения и файлы не удаляются.

## Способ 2 — только через браузер

1. Открой **Supabase → SQL Editor → New query**.
2. Открой файл `supabase/migrations/0015_journey_reader_order.sql` из архива.
3. Скопируй файл целиком в SQL Editor и нажми **Run** один раз.
4. Открой **Supabase → Edge Functions → public-timeline** и замени код содержимым `supabase/functions/public-timeline/index.ts`.
5. Так же обнови `get-media-url` из `supabase/functions/get-media-url/index.ts`.
6. У обеих функций переключатель **Verify JWT** должен оставаться выключенным — доступ проверяется reader-token внутри функции.
7. Нажми **Deploy** у обеих функций.

Если редактор Supabase не позволяет подключить соседние `_shared`-файлы к функции, используй способ с CLI: текущая функция импортирует общие модули проекта.

## Заменить проект в GitHub

1. Распакуй архив `aiailock-journey-reader-0015.zip`.
2. Открой папку проекта внутри архива.
3. В GitHub открой `Aiailock/aiailock`.
4. Нажми **Add file → Upload files**.
5. Перетащи **содержимое** распакованной папки, а не сам ZIP.
6. Подтверди замену файлов и сделай Commit в `main`.

Если загружаешь с Android и браузер не выбирает папки, включи «Версия для ПК» или используй GitHub-приложение/Termux. Сам ZIP в репозиторий загружать бессмысленно: GitHub его не распакует.

## Опубликовать на Netlify

После commit Netlify обычно запускается сам.

1. Открой **Netlify → Deploys**.
2. Дождись статуса **Published**.
3. Если сборка не началась: **Trigger deploy → Clear cache and deploy site**.

Настройки остаются прежними:

```text
Build command: npm run build
Publish directory: dist
Node: 20
```

Переменные остаются только эти:

```text
VITE_SUPABASE_URL
VITE_SUPABASE_ANON_KEY
```

## Как добавлять вопросы и новые моменты

1. Войди в `/admin/login`.
2. Открой **Добавить → Сюрприз**.
3. В поле «Как открывается» выбери вопрос, развилку, шкалу, защитный слой, желание или созвездие.
4. Для вопроса/развилки укажи два варианта и, при желании, отдельный ответ после каждого выбора.
5. Выбери оформление и анимацию.
6. Нажми «Добавить» и проверь в Preview.

Быстрый вариант доступен и в **История → `+` между карточками**. Для точных вариантов ответа удобнее использовать вкладку «Добавить».

## Проверка после обновления

1. В Admin → «История» переставь тестовую карточку выше или ниже.
2. Обнови список и убедись, что дата карточки не изменилась.
3. Открой Preview и проверь тот же порядок сверху вниз.
4. Перезагрузи reader: сначала должен появиться экран подготовки с процентами.
5. После 100% пролистай фото — они должны появляться без отдельного ожидания.
6. Проверь сообщения утром, днём, вечером и ночью: атмосферы должны отличаться.
7. Создай тестовый «Вопрос» и «Созвездие».
8. Открой карту снизу, поставь закладку, измени размер текста и включи автопрокрутку.
9. Проверь ширины 320, 390 и 430 пикселей.

## Если что-то пошло не так

- Ошибка `column display_order does not exist`: миграция `0015` ещё не применена.
- Reader бесконечно загружается: переопубликуй `public-timeline` после миграции.
- Reader показывает старую версию: в Netlify запусти **Clear cache and deploy site** и очисти кэш/PWA сайта в браузере.
- Одно фото не открылось, но история загрузилась: проверь путь файла в Admin → «Медиа»; один повреждённый файл специально не блокирует всю книгу.
- На слабом интернете первая загрузка стала длиннее: это ожидаемо — reader заранее готовит все фото, чтобы само чтение шло плавно.

## Откат

Frontend можно вернуть на предыдущий commit. Колонку `display_order` удалять не нужно: старой версии она не мешает. Перед любыми ручными изменениями схемы сначала сделай backup базы.
