# UPDATE 0020 — Local AI Story Director

Это обновление **не переделывает твою уже готовую историю**. Оно добавляет в `/admin` отдельный режим «ИИ-режиссёр», который читает опубликованную последовательность, учитывает уже существующие фото, GIF, музыку, видео, главы и паузы и предлагает только точечные дополнения.

## Что добавлено

- Локальный ИИ в браузере администратора через WebGPU.
- Никаких OpenAI / Claude / Gemini API и никаких оплат за токены.
- Два локальных варианта модели: Qwen3 0.6B и Qwen3 1.7B.
- Три режима плотности: «Очень аккуратно», «Умеренно», «Кинематографично».
- Структурный fallback без LLM, если WebGPU на устройстве недоступен.
- Анализ уже опубликованной истории по реальному `display_order`.
- ИИ учитывает плотность текста, наличие медиа рядом, временные разрывы, смену настроения и важные моменты.
- Типы предложений: пауза, глава, цитата, GIF, картинка, видео, музыка и ссылка.
- Бесплатный поиск картинок/GIF/видео через Wikimedia Commons без API-ключа.
- Музыка выбирается через уже существующий в проекте бесплатный поиск официальных превью.
- Каждое предложение можно включить/выключить, изменить тип, название, текст и медиа.
- Предложения сначала сохраняются как AI-черновик.
- Настоящий Reader-preview показывает скрытые AI-сцены только авторизованному администратору.
- Обычный Reader не получает эти сцены, пока ты не нажмёшь «Опубликовать выбранное».
- Существующие сообщения, `original_text`, `display_text`, фото, GIF, музыка и другие элементы не переписываются и не удаляются.
- AI-черновики добавлены в JSON backup раздела «Сохранность».

## Почему это 0 ₸

Само LLM-выполнение идёт **на твоём компьютере в браузере**, а не на платном AI API. Модель один раз скачивается в кэш браузера и дальше выполняет запросы локально. В патче намеренно зафиксирован WebLLM `0.2.82`, потому что в более новых `0.2.83/0.2.84` на части интегрированных GPU есть известная регрессия.

Поиск Wikimedia Commons работает анонимно через публичный MediaWiki API с `origin=*`, без ключа. Музыкальный поиск использует уже имеющийся в проекте механизм превью.

Важно: это означает **0 ₸ за AI-запросы и отсутствие платных API**, но твой проект всё равно остаётся в рамках обычных бесплатных лимитов Netlify/Supabase. Если когда-нибудь превысишь их free-tier, это уже не стоимость ИИ-режиссёра.

## Что ИИ НЕ делает

- не публикует сам;
- не удаляет существующие страницы;
- не меняет твои исходные сообщения;
- не придумывает URL картинок/видео;
- не обязан вставлять что-то между каждой страницей;
- не отправляет историю в OpenAI/Claude/Gemini.

Если рядом уже стоит музыка, GIF, фотография или глава, алгоритм специально снижает шанс ещё одной вставки. В режиме «Очень аккуратно» лучше получить 8–15 хороших идей, чем сотню украшений.

# Установка для Windows

## Вариант 1 — самый простой

1. Распакуй папку `aiailock-0020-patch` **внутрь корня твоего репозитория**. В итоге рядом должны быть примерно:

```text
aiailock/
  src/
  supabase/
  package.json
  aiailock-0020-patch/
    install_0020.bat
    install_0020.py
```

2. Дважды нажми:

```text
aiailock-0020-patch\install_0020.bat
```

Установщик сам создаёт `.pre-0020.bak` для изменяемых существующих файлов.

## Вариант 2 — через терминал

Из корня проекта:

```bat
py aiailock-0020-patch\install_0020.py
```

Если патч лежит в другом месте:

```bat
py C:\путь\aiailock-0020-patch\install_0020.py C:\путь\aiailock
```

# После установки файлов

Открой CMD/PowerShell **в корне проекта** и выполни по очереди:

```bat
npx supabase@latest login
npx supabase@latest link --project-ref ТВОЙ_PROJECT_REF
npx supabase@latest db push
npx supabase@latest functions deploy public-timeline
npm run build
```

Если `supabase` у тебя уже залогинен и linked, первые две команды повторять не нужно.

Если `npm run build` завершился без ошибки:

```bat
git add .
git commit -m "Add local AI story director"
git push
```

Netlify после push соберёт frontend как обычно.

# Как пользоваться

1. Открой:

```text
https://твой-сайт.netlify.app/admin
```

2. В меню появится **«ИИ-режиссёр»**.

3. На компьютере лучше использовать актуальный Chrome или Edge с WebGPU.

4. Выбери модель:
   - **Qwen3 0.6B** — сначала попробуй её. Она легче.
   - **Qwen3 1.7B** — если компьютер нормально тянет и хочешь лучшее понимание контекста.

5. Нажми **«Загрузить локальный ИИ»**. Первая загрузка модели заметно тяжелее последующих, потому что браузер сохраняет её в кэш.

6. Оставь режим **«Очень аккуратно»**.

7. Нажми **«Проанализировать всю готовую историю»**.

8. Получишь только найденные предложения. Например:
   - пауза между тяжёлым текстом и следующей сценой;
   - глава после большого временного разрыва;
   - идея GIF после лёгкого/смешного блока;
   - картинка для визуального воздуха;
   - песня для ночного эмоционального перехода.

9. Сними галочки с лишнего. Отредактируй текст, если нужно.

10. Для GIF/картинки/видео можно нажать бесплатный поиск Wikimedia Commons и выбрать файл. Можно также вставить свою прямую ссылку.

11. Для музыки воспользуйся встроенным поиском песни.

12. Нажми **«Предпросмотр выбранных»**.

Новые элементы будут записаны как `is_published=false` и появятся только в специальном admin-preview `/?preview=1&aiBatch=...`.

13. Прочитай участок прямо в настоящем Reader. Если не нравится — **«Убрать черновик»**. Опубликованная история останется прежней.

14. Если всё устраивает — **«Опубликовать выбранное»**.

Только после этого сцены получат `is_published=true` и появятся у читателя.

# Если WebGPU не работает

Это не ломает сайт. «ИИ-режиссёр» переключается на бесплатный структурный анализ: он ищет большие временные разрывы и слишком плотные текстовые участки и предлагает паузы/главы без выдуманных чувств.

Для полноценного локального смыслового анализа лучше открыть `/admin` на обычном ПК/ноутбуке в Chrome/Edge, а не на телефоне.

# Безопасность истории

AI-черновики живут отдельно в:

```text
ai_story_batches
ai_story_suggestions
```

До предпросмотра они вообще не попадают в `timeline_elements`. При предпросмотре одобренные предложения становятся скрытыми `timeline_elements` (`is_published=false`). Обычный `public-timeline` по-прежнему читает только опубликованные элементы.

Специальный AI-preview разрешается только если Edge Function подтверждает, что запрос пришёл от владельца через `assertAdmin()`.

# Откат файлов

Установщик сохраняет резервные копии изменяемых файлов с окончанием:
