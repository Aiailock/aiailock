## 2. Найден и исправлен реальный баг
`server/media/thumbnail.ts` (используется Deno-функцией `import-zip` для генерации
превью фото) начинался и заканчивался строками ```` ```ts ```` / ```` ``` ```` —
явно случайно оставшиеся markdown-обрамления кода из предыдущей сессии. Это
синтаксическая ошибка, `tsc` её не ловил, потому что этот файл не входит в
Node/Vite-проект (он предназначен только для Deno-рантайма Supabase). При
реальном деплое `supabase functions deploy import-zip` эта функция бы не
задеплоилась вообще. Убрал обе строки.

## Что осталось не проверено «вживую» (честно, как и в предыдущих сессиях)
В этой песочнице нет Deno и нет доступа к реальному проекту Supabase/Netlify,
поэтому не проверено:
- Реальный деплой Edge Functions (`supabase functions deploy ...`).
- Реальная загрузка в Supabase Storage и генерация миниатюр через
  `@imagemagick/magick-wasm` под настоящим Deno-рантаймом.
- RLS-политики против живой базы.
- Деплой на Netlify.

Это не «то же самое, что не работает» — код прошёл ручной построчный разбор и
все автотесты, которые можно прогнать без Deno, реально прошли. Но финальную
проверку (загрузить тестовый ZIP с фото/видео/аудио на реальном проекте)
должен сделать пользователь после деплоя — я не могу подключиться к чужому
Supabase/Netlify аккаунту из этой среды.
