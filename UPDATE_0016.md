# Глобальное обновление 0016 — плавность, загрузка и мнения

Обновление продолжает существующий проект. Оно не удаляет историю, импортированные сообщения, фотографии, настройки, пользователей Supabase или файлы Storage.

## Что изменено

1. Reader больше не пытается скачать всю историю до первого показа. Сначала открывается первая часть, следующие страницы подгружаются заранее по мере чтения.
2. Убраны самые тяжёлые причины рывков: отдельный scroll-параллакс у каждой записи, вечная анимация каждого фона и одновременная работа всех частиц вне экрана.
3. Длинная история разбита на изолированные экранные блоки. Браузер не перерисовывает далёкие страницы во время прокрутки.
4. Добавлен автоматический облегчённый режим для телефонов с небольшим объёмом памяти, четырьмя и менее ядрами, медленным соединением или включённой экономией трафика.
5. В Admin → Настройки можно выбрать режим эффектов: «Автоматически», «Все эффекты» или «Облегчённый».
6. Новая загрузка по умолчанию показывает три сердечка и текст «Моя история грузится».
7. В Admin → Настройки можно менять заголовок, пояснение и вид загрузки: сердечки, искры или минимальное кольцо.
8. У каждой записи, фотографии, главы, цитаты, паузы, воспоминания, особого момента и альбома появилась компактная кнопка «Оставить своё мнение».
9. Она может выбрать эмодзи и написать до 600 символов. Мнение можно изменить позже с того же телефона.
10. Текстовые мнения отображаются у владельца в Admin → Статистика вместе с реакцией, временем и номером страницы.
11. Кнопка «+» → «Альбом» принимает до 12 скриншотов за несколько выборов, показывает мобильные превью, общий размер и позволяет изменить порядок или удалить отдельный файл до сохранения.
12. Скриншоты альбома загружаются по три одновременно и записываются одной операцией, поэтому сохранение заметно быстрее.
13. Если пакетная загрузка не удалась, уже загруженные временные файлы удаляются автоматически.
14. Автопрокрутка переведена на синхронизацию с кадрами экрана вместо постоянного таймера.
15. События статистики прокрутки объединяются, чтобы не отправлять лишние запросы при быстром листании.
16. Предзагрузка фотографий ограничена ближайшими страницами и двумя параллельными файлами, чтобы не забивать память и интернет телефона.
17. Сохранённое место чтения работает и для очень длинной истории: нужная часть запрашивается отдельно, без загрузки всех предыдущих страниц.
18. Ошибка следующей части больше не ломает всю книгу — появляется отдельная кнопка повторной загрузки.

## Обновление уже работающего проекта

### 1. Сделай резервную копию

Скачай текущий репозиторий с GitHub через **Code → Download ZIP**. База и Storage этим обновлением не очищаются, но копию проекта лучше сохранить.

### 2. Замени файлы проекта

Распакуй архив обновления и замени его файлами содержимое репозитория. Не переноси из старой копии папки `node_modules` и `dist`. Свои `.env`/переменные Netlify оставь прежними.

Если работаешь через Git:

```bash
git add .
git commit -m "Smooth reader and written opinions"
git push origin main
```

### 3. Примени новую миграцию Supabase

Открой терминал в корне проекта. Для твоего уже связанного проекта достаточно:

```bash
npx supabase@latest db push
```

Команда должна применить файл:

```text
0016_reader_opinions_performance.sql
```

Если папка ещё не связана с Supabase:

```bash
npx supabase@latest login
npx supabase@latest link --project-ref YOUR_PROJECT_REF
npx supabase@latest db push
```

### 4. Обнови Edge Function мнений

```bash
npx supabase@latest functions deploy reader-reaction
```

Остальные Edge Functions в этом обновлении не менялись и повторно публиковать их не обязательно.

### 5. Дождись Netlify

После `git push` Netlify автоматически начнёт новый deploy. Настройки остаются прежними:

```text
Build command: npm run build
Publish directory: dist
Node: 20
```

Переменные Netlify также остаются прежними:

```text
VITE_SUPABASE_URL
VITE_SUPABASE_ANON_KEY
```

Если автодеплой отключён, открой Netlify → **Deploys → Trigger deploy → Deploy site**.

### 6. Проверка после деплоя

1. Открой главную ссылку сайта в обычном режиме, не через `/admin`.
2. Убедись, что показались сердечки и текст загрузки, а первая часть истории открылась без ожидания всей книги.
3. Прокрути несколько экранов вниз и проверь, что рывков стало меньше.
4. Открой любую запись → «Оставить своё мнение» → выбери эмодзи, напиши текст и сохрани.
5. Открой `/admin` → «Статистика» и проверь появившееся мнение.
6. Открой `/admin` → кнопка «+» → «Альбом», выбери несколько скриншотов, измени их порядок и сохрани.
7. Открой Admin → Настройки → «Загрузка истории», измени текст или анимацию и сохрани.

## Если браузер показывает старую версию

PWA обновляется автоматически, но уже открытая вкладка может ещё держать старый код. Полностью закрой вкладку и открой сайт заново. Если это не помогло, очисти данные только этого сайта в настройках браузера и снова открой ссылку.

## Безопасный откат

Миграция лишь добавляет необязательное поле `note` в `reader_reactions` и не меняет существующую историю. Старый frontend продолжит работать даже после миграции. Для отката достаточно вернуть предыдущий commit и снова дождаться Netlify; удалять столбец из базы не требуется.
