# Обновление 0017 — подробная статистика чтения

Это обновление продолжает существующий проект и не удаляет историю, сообщения, фотографии, настройки, аккаунт администратора или файлы Supabase Storage.

## Что добавлено

1. Последняя прочитанная точка теперь показывается понятным названием: например, **«Сообщение · №210»**, **«Скриншот · №84»** или названием воспоминания/главы.
2. Под названием выводится короткий отрывок текста. Больше не нужно угадывать, что означает технический идентификатор вроде `4ce6c989`.
3. Для реакций и письменных мнений также видны название записи, её номер, дата и отрывок.
4. Запоминается глава, в которой читатель остановился.
5. Для каждого устройства отображаются тип устройства, модель (если браузер её сообщает), браузер, операционная система, экран, размер окна, язык и часовой пояс.
6. Дополнительно показываются доступные сведения о процессоре, памяти, типе соединения, скорости и режиме экономии трафика.
7. Каждое открытие хранит собственный снимок устройства — можно понять, с чего читали именно в этот раз.
8. В списке открытий появилась длительность активности, точка остановки и процент прогресса.
9. Добавлена кнопка **«Очистить»**. Она удаляет все открытия, устройства, прогресс и последнюю точку.
10. В подтверждении можно выбрать, удалять ли одновременно реакции и написанные мнения.
11. Очистка статистики не затрагивает саму историю, медиа, настройки и импорт.
12. Старая статистика получает понятные названия и отрывки там, где соответствующая запись ещё существует. Полные сведения об устройстве появятся после нового открытия сайта.

> Важно: браузеры не всегда сообщают точную модель. На iPhone обычно будет видно «Apple iPhone» без номера модели. Это ограничение самого браузера, а не ошибка сайта. Точный IP-адрес обновление не сохраняет.

## Как установить обновление

### 1. Сохрани резервную копию

В GitHub открой репозиторий и нажми **Code → Download ZIP**. База обновлением не очищается, но резервная копия текущего кода пригодится для отката.

### 2. Замени файлы проекта

Распакуй архив обновления и замени его файлами содержимое репозитория. Не загружай папки `node_modules` и `dist`. Переменные Netlify и свои локальные `.env` оставь прежними.

Если используешь Git:

```bash
git add .
git commit -m "Detailed reader analytics"
git push origin main
```

### 3. Примени миграцию Supabase

Открой терминал в корне новой папки проекта:

```bash
npx supabase@latest login
npx supabase@latest link --project-ref YOUR_PROJECT_REF
npx supabase@latest db push
```

Если эта папка уже связана с нужным Supabase-проектом, достаточно:

```bash
npx supabase@latest db push
```

В конце должна примениться миграция:

```text
0017_detailed_reader_analytics.sql
```

### 4. Обнови функцию статистики

После успешного `db push` выполни:

```bash
npx supabase@latest functions deploy reader-analytics
```

Остальные Edge Functions в этом обновлении не менялись.

### 5. Дождись Netlify

После загрузки файлов или `git push` Netlify автоматически соберёт сайт. Настройки остаются прежними:

```text
Build command: npm run build
Publish directory: dist
Node: 20
```

Новые переменные окружения не нужны. Сохрани существующие:

```text
VITE_SUPABASE_URL
VITE_SUPABASE_ANON_KEY
```

Если автоматический деплой выключен, в Netlify открой **Deploys → Trigger deploy → Deploy site**.

## Как проверить

1. Открой обычную главную страницу сайта не через режим Preview.
2. Пролистай несколько записей и закрой вкладку.
3. Зайди в `/admin` → **Чтение** и нажми **Обновить**.
4. Проверь блок **«Последняя прочитанная точка»** — там должны быть название, номер, отрывок, дата и прогресс.
5. Проверь блок **«Устройства»** и список **«Последние открытия»**.
6. Оставь реакцию на любой записи и убедись, что вместо технического ID показана понятная запись истории.
7. Нажми **«Очистить»**, проверь текст подтверждения и при необходимости отключи удаление реакций.

## Безопасный откат

Можно вернуть предыдущую версию frontend и функции `reader-analytics`. Миграция 0017 только добавляет поля, представление и функцию очистки, поэтому существующая история продолжит работать. Удалять добавленные столбцы для отката не требуется.
