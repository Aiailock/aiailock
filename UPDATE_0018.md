# Обновление 0018 — видео, переходы и рандомное оформление

Обновление продолжает текущий проект и не удаляет историю, импорт, фотографии, реакции, статистику, настройки или аккаунт администратора.

## Что добавлено

1. В кнопке `+` между записями появился пункт **«Видео»**.
2. Видео можно загрузить файлом до 200 МБ в приватный bucket `videos` или указать прямую ссылку на MP4/WebM.
3. Загруженное видео использует уже существующую защищённую выдачу временных ссылок и обычный reader-плеер.
4. В кнопке `+` появился пункт **«Ссылка»** с названием и описанием перехода.
5. Для ссылки есть два режима: открыть сайт в новой вкладке или показать его маленьким окном прямо внутри истории.
6. Если сторонний сайт запрещает встраивание, под мини-окном остаётся кнопка открытия в новой вкладке.
7. Видео и ссылки также доступны в мобильной вкладке Admin → **«Добавить»**.
8. Ссылку или видео по URL можно позже изменить прямо в Admin → **«История»**.
9. После выбора нескольких элементов появилась кнопка **«Рандом каждой»**.
10. Каждая выбранная запись получает своё сочетание рамки, шрифта, фона, дизайна даты, выравнивания, воздуха, анимации и эффекта.
11. Рандом меняет оформление воспоминаний и скриншотов в их исходных таблицах тоже, поэтому стиль не откатывается при следующем редактировании.
12. Новые видео и переходы получают понятные названия в подробной статистике чтения.
13. Проверяется полный адрес ссылки: разрешены только `http://` и `https://`.
14. При неудачной загрузке видео незавершённые записи и файл автоматически очищаются.

## Как установить

### 1. Сохрани резервную копию

В GitHub нажми **Code → Download ZIP** или сохрани текущую рабочую папку отдельно.

### 2. Замени файлы проекта

Замени содержимое репозитория файлами обновления. Не загружай `node_modules` и `dist`. Переменные `.env` и настройки Netlify оставь прежними.

Если используешь Git:

```bash
git add .
git commit -m "Video links and random story styles"
git push origin main
```

### 3. Сначала обнови Supabase

Открой терминал в корне проекта и выполни:

```bash
npx supabase@latest login
npx supabase@latest link --project-ref YOUR_PROJECT_REF
npx supabase@latest db push
```

Если папка уже связана с нужным проектом, достаточно:

```bash
npx supabase@latest db push
```

Должна примениться миграция:

```text
0018_video_links_random_styles.sql
```

Она добавляет тип `link`, функцию случайного оформления и понятные подписи для статистики. Существующие данные не очищаются.

### 4. Обнови функцию статистики

```bash
npx supabase@latest functions deploy reader-analytics
```

Остальные Edge Functions в этом обновлении не менялись. Новые секреты и переменные окружения не нужны.

### 5. Дождись Netlify

После `git push` Netlify соберёт обновлённый frontend автоматически. Настройки прежние:

```text
Build command: npm run build
Publish directory: dist
Node: 20
```

## Как проверить

1. Открой `/admin` → **«История»** и нажми `+` между двумя записями.
2. Выбери **«Видео»**, загрузи небольшой MP4 и проверь его в Preview.
3. Добавь **«Ссылку»** сначала как переход, затем как мини-окно.
4. Выбери галочками 3–5 обычных записей и нажми **«Рандом каждой»**.
5. Убедись, что выбранные записи получили разные стили.
6. Открой обычную главную страницу, дойди до новых элементов и затем проверь Admin → **«Чтение»**.

> Не каждый сайт разрешает показ внутри `iframe`. Это правило самого стороннего сайта. В таком случае переход всё равно работает через кнопку «открыть отдельно».

## Безопасный откат

Можно вернуть предыдущий frontend и функцию `reader-analytics`. Миграция 0018 только расширяет допустимые типы и добавляет функцию/подписи, поэтому существующая история продолжит работать. Удалять миграцию из уже обновлённой базы не требуется.
