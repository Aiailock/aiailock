# Обновление 0019 — музыка, своё аудио и виниловый плеер

Это полный проект: в архив уже входят все предыдущие функции, обновление 0018 (видео, ссылки, мини-окно и случайное оформление) и новое музыкальное обновление 0019. Существующая история, фотографии, импорт WhatsApp, статистика, настройки и аккаунт администратора не удаляются.

## Что добавлено

1. В каждой кнопке `+` между элементами истории появился пункт **«Музыка»**.
2. Музыка также доступна в мобильном Admin → **«Добавить»**.
3. Можно найти песню по названию или исполнителю прямо в форме добавления.
4. Поиск работает через публичный каталог iTunes без отдельного API-ключа или нового секрета Supabase.
5. В результате видны обложка, название, исполнитель, альбом и короткое официальное аудиопревью.
6. Выбранная песня сохраняется в истории с обложкой и ссылкой на страницу каталога.
7. Для полного трека можно загрузить свой аудиофайл до 25 МБ: MP3, M4A, AAC, WAV, OGG, FLAC или аудио WebM.
8. Для своего аудио можно добавить отдельную обложку до 5 МБ, название, исполнителя и подпись.
9. Своё аудио и обложка хранятся в уже существующих приватных bucket `audio` и `thumbnails`.
10. Reader получает только временные подписанные ссылки, как и для остальных приватных медиа.
11. В Reader появился тёмный музыкальный плеер с пластинкой, обложкой, кнопкой play/pause, волной, перемоткой, временем и повтором с начала.
12. Во время воспроизведения винил плавно крутится. При системной настройке «меньше движения» вращение отключается.
13. Для найденных песен плеер честно показывает отметку **«30 сек. превью»**.
14. Музыкальную карточку, добавленную поиском, можно позже отредактировать в Admin → **«История»**.
15. В подробной статистике чтения теперь показываются название аудио и исполнитель, а не безликое «Аудиосообщение».
16. Исправлен лишний прогрев прямых ссылок на видео и аудио через тег изображения, поэтому Reader не делает ненужный запрос как к картинке.

## Важно о найденных песнях

Поиск добавляет доступное в каталоге короткое официальное превью, а не скачивает полный защищённый авторским правом трек. Доступность конкретной песни и превью зависит от страны и каталога Apple. Если нужен полный трек, загрузи собственный аудиофайл, на использование которого у тебя есть право.

## Как установить обновление в существующий проект

### 1. Сделай резервную копию

Перед заменой файлов скачай текущий репозиторий через GitHub → **Code → Download ZIP** или создай отдельную копию папки.

### 2. Замени файлы проекта

Распакуй архив обновления и замени содержимое репозитория. Не переноси в GitHub папки `node_modules`, `dist` и файл `.env`.

Твои существующие переменные Netlify остаются прежними:

```text
VITE_SUPABASE_URL
VITE_SUPABASE_ANON_KEY
```

Если работаешь через Git:

```bash
git add .
git commit -m "Add music search uploads and vinyl player"
git push origin main
```

### 3. Примени миграции Supabase

В терминале из корня проекта:

```bash
npx supabase@latest login
npx supabase@latest link --project-ref YOUR_PROJECT_REF
npx supabase@latest db push
```

Если проект уже связан с Supabase, достаточно:

```bash
npx supabase@latest db push
```

Если обновление 0018 раньше не ставилось, применятся обе миграции по порядку:

```text
0018_video_links_random_styles.sql
0019_music_vinyl_audio.sql
```

Миграция 0019 не создаёт новую таблицу и не изменяет существующие файлы. Она обновляет понятные подписи музыкальных элементов для статистики чтения.

### 4. Обнови Edge Function статистики

```bash
npx supabase@latest functions deploy reader-analytics
```

Остальные Edge Functions для этого обновления менять не требуется. Новые API-ключи, секреты и переменные окружения не нужны.

### 5. Дождись сборки Netlify

После `git push` Netlify запустит обычную сборку:

```text
Build command: npm run build
Publish directory: dist
Node: 20
```

## Как добавить найденную песню

1. Открой Admin → **«История»**.
2. Нажми `+` между нужными сообщениями.
3. Выбери **«Музыка»** → **«Найти песню»**.
4. Введи исполнителя и название, затем нажми **«Найти»**.
5. Прослушай короткое превью и нажми **«Выбрать»**.
6. При желании добавь подпись «почему эта песня здесь».
7. Нажми **«Добавить сюда»**.

То же самое доступно через Admin → **«Добавить»** → **«Музыка»**.

## Как загрузить своё аудио

1. Выбери **«Музыка»** → **«Загрузить аудио»**.
2. Укажи аудиофайл до 25 МБ.
3. Введи название и исполнителя.
4. При желании выбери квадратную обложку до 5 МБ и напиши подпись.
5. Добавь элемент и проверь его в Preview.

Лучше использовать MP3 или M4A: они поддерживаются большинством современных браузеров. FLAC/WAV обычно весят больше и могут не поместиться в лимит 25 МБ.

## Проверка после установки

1. Через `+` найди песню и добавь её в середину истории.
2. Открой Preview, нажми play и проверь вращение пластинки, перемотку и обложку.
3. Загрузить небольшой собственный MP3 с обложкой и убедись, что он тоже воспроизводится.
4. Открой Admin → **«История»**, найди музыкальную карточку из поиска и измени её подпись.
5. Открой обычную Reader-страницу, дойди до музыки, затем проверь Admin → **«Чтение»**.
6. Убедись, что ранее добавленные видео, ссылки и случайные стили из 0018 сохранились.

## Безопасный откат

Можно вернуть предыдущий frontend и предыдущую версию функции `reader-analytics`. Миграция 0019 только обновляет представление статистики и не удаляет данные, поэтому откатывать или удалять её из базы не нужно. Уже загруженные аудиофайлы останутся в приватном Storage; удалить ненужный элемент вместе с медиа можно через Admin.
