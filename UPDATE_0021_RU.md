## Безопасный порядок обновления без локального проекта

### 1. Сделать резервную копию

На GitHub открой репозиторий → **Code → Download ZIP**. В Supabase желательно создать резервную копию базы штатными средствами проекта.

### 2. Загрузить код сначала в отдельную ветку

1. На GitHub создай ветку `update-0021` от `main`.
2. Распакуй архив этого обновления.
3. Через **Add file → Upload files** загрузи содержимое папки проекта в ветку `update-0021` с заменой совпадающих файлов.
4. Не загружай свои `.env` и ключи. Папки `node_modules` и `dist` в архив обновления не включены.

Так `main` и действующий Netlify-сайт не изменятся, пока Supabase не будет готов.

### 3. Применить SQL в Supabase

Открой **Supabase Dashboard → SQL Editor → New query**, скопируй целиком файл:

`supabase/migrations/0021_reader_media_ai_update.sql`

Нажми **Run**. Скрипт создаёт только служебное представление списка глав и не меняет содержимое истории.

### 4. Обновить три Edge Functions через браузерный Codespaces

В ветке `update-0021` нажми **Code → Codespaces → Create codespace**. В открывшемся терминале выполни по очереди, заменив `YOUR_PROJECT_REF` на идентификатор Supabase-проекта:

```bash
npx supabase@latest login
npx supabase@latest functions deploy public-timeline --project-ref YOUR_PROJECT_REF
npx supabase@latest functions deploy get-media-url --project-ref YOUR_PROJECT_REF
npx supabase@latest functions deploy ai-director --project-ref YOUR_PROJECT_REF
```

`project ref` виден в Supabase Dashboard → **Project Settings → General** и в адресе проекта. Секрет OpenRouter в настройках Supabase добавлять не нужно: владелец вставляет личный ключ непосредственно на странице AI‑режиссёра, и сайт не сохраняет его.

### 5. Выпустить обновление на Netlify

1. На GitHub открой Pull Request `update-0021` → `main` и нажми **Merge**.
2. Netlify автоматически соберёт новый коммит.
3. В Netlify проверь **Deploys**: статус должен стать **Published**.
4. Если телефон продолжает показывать старый PWA-интерфейс, полностью закрой вкладку и открой сайт заново. При необходимости в Netlify запусти **Clear cache and deploy site**.

Для сборки нужны прежние переменные Netlify `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY`; новых переменных не появилось.

## Как настроить функции на самом сайте

### Записать голосовое

Админка → **Быстрое создание** → **Голосовое** → разрешить микрофон → **Начать запись** → **Остановить и сохранить**. Запись можно прослушать и перезаписать до публикации. То же доступно в **Единой истории** через кнопку `+` между элементами. Микрофон работает на HTTPS‑адресе Netlify.

### Выбрать дизайн аудио

При создании голосового или музыки открой **Вид аудиоплеера** и выбери один из пяти вариантов. Для уже существующего аудио: **Единая история → Оформление → Вид аудиоплеера → Сохранить оформление**. Старые музыкальные записи по умолчанию остаются виниловыми, обычные аудиозаписи выглядят как голосовые.

### Найти GIF

Выбери **GIF**, введи запрос в блоке **Бесплатный поиск Wikimedia Commons**, нажми лупу и выбери карточку. Ссылка на источник сохраняется в метаданных. Перед публикацией проверь лицензию конкретного файла по ссылке источника. Своя ссылка и загрузка `.gif` также доступны.

### Фоновая музыка

Админка → **Настройки** → **Фоновая музыка Reader**:

- **Встроенная** — новая спокойная композиция;
- **Своя** — аудиофайл до 25 МБ;
- **Выключена** — фон не загружается.

Там же меняются название и громкость. У читателя в правом верхнем углу всегда есть кнопка включения/выключения. Из-за правил браузеров музыка начинает играть после первого касания страницы. Во время обычного аудио или видео фон автоматически становится почти неслышным.

### Бесплатный AI‑режиссёр

1. Создай аккаунт на <https://openrouter.ai/>.
2. Открой <https://openrouter.ai/keys> и создай ключ.
3. На сайте открой **Админка → AI‑режиссёр**.
4. Оставь режим **Облачно · бесплатно**, вставь ключ и выбери интенсивность.
5. Нажми **Проанализировать всю готовую историю**.
6. Проверь предложения, подготовь предпросмотр и только затем публикуй выбранное.

Используется маршрутизатор `openrouter/free`. Он выбирает доступную бесплатную модель; наличие моделей и дневные лимиты определяет OpenRouter. Ключ живёт только в памяти текущей вкладки, не пишется в базу и не сохраняется в браузере. В OpenRouter передаются только ограниченные фрагменты вокруг найденных переходов. Для полностью локальной работы выбери **На этом устройстве**; если снова появится `Quota exceeded`, нажми **Очистить кэш локальной модели** либо используй облачный режим.

## Сброс прогресса и списка читателей

В Supabase SQL Editor выполни файл `RESET_READER_PROGRESS.sql`. Его команда:

```sql
begin;
delete from public.reader_visits;
delete from public.reader_visitors;
commit;
```

Она удаляет визиты, прогресс и список читателей. История, файлы, настройки и реакции остаются. У уже открывавшего сайт человека локальная закладка может сохраниться на его устройстве, но серверная статистика начнётся заново при следующем визите.

## Проверка после публикации

1. С телефона запиши короткое голосовое, прослушай и сохрани.
2. Открой Reader, запусти голосовое и видео: фоновая музыка должна приглушиться и вернуться после паузы.
3. Переключи три размера текста.
4. Открой карту, выбери последнюю главу и сохрани закладку.
5. Найди GIF через поиск и открой ссылку источника.
6. Запусти AI‑режиссёра сначала в облачном режиме; ничего не публикуй до проверки Reader preview.

Производственная сборка этого пакета проверена командой `npm run build`.
