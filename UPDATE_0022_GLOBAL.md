# Глобальное обновление 0022

Это полное обновление существующего проекта **aiailock**. Оно не удаляет историю, импортированные сообщения, фотографии, статистику или настройки. Новая миграция только добавляет таблицу ответов на вопросы и увеличивает допустимый размер аудиофайла.

## Что исправлено

1. ИИ-редактор больше не застревает на первых 100 уже обработанных сообщениях.
2. Результат ИИ больше не выглядит пустым: видно «изменений не нужно», исправленный вариант или понятную ошибку.
3. Исправлена обработка небольших опечаток: раньше защита отклоняла даже безопасную замену одной буквы.
4. Добавлен бесплатный OpenRouter-ключ прямо во вкладку ИИ; он не записывается в базу и браузер.
5. Ответы разных бесплатных моделей разбираются и как строка, и как массив текстовых блоков.
6. Если облачная модель недоступна, редактор безопасно оставляет исходный текст вместо пустой записи.
7. В ИИ появился ручной редактор с сохранением и неизменяемым оригиналом.
8. GIF из поиска теперь копируется в приватное Supabase Storage, поэтому не пропадает из-за внешней ссылки.
9. Для старых GIF во вкладке «История» появились «Сохранить GIF надёжно» и «Загрузить GIF».
10. Reader показывает понятную заглушку, если старый GIF действительно недоступен.
11. Поиск музыки больше не сохраняет 30-секундный фрагмент в историю.
12. Музыка добавляется полным аудиофайлом или прямой ссылкой на полный MP3/M4A/OGG.
13. Поиск песни используется только для названия, исполнителя и обложки.
14. Лимит аудиофайла увеличен с 25 до 60 МБ.
15. На телефоне вместо 14 вкладок в одну строку появился нижний бар из четырёх главных разделов и кнопки «Ещё».
16. Все разделы собраны в четыре понятные группы: «Главное», «Контент», «Умные инструменты», «Контроль».
17. Админка запоминает последний открытый раздел и записывает его в адрес страницы.
18. В мобильной мастерской кнопка сохранения всегда остаётся под рукой.
19. Поля на iPhone/Android не увеличивают страницу при вводе и не ломают ширину длинными ссылками.
20. Разрешён микрофон на собственном HTTPS-сайте для записи голосовых.
21. Вопрос теперь поддерживает четыре варианта и отдельный красивый ответ после каждого выбора.
22. Читатель может изменить выбранный вариант; результат сохраняется на устройстве даже при временной ошибке сети.
23. Ответ на вопрос отправляется в Supabase и виден администратору во вкладке «Чтение».
24. Общая очистка аналитики может удалить также ответы на вопросы.

## Важно о полной музыке

Открытые каталоги отдают только короткие ознакомительные фрагменты и не дают законно скачивать полный трек. Поэтому обновление не маскирует 30 секунд под полную песню. Для полного воспроизведения загрузите аудиофайл, который вам разрешено использовать, либо вставьте прямую ссылку на принадлежащий вам аудиофайл. Ссылка на страницу Spotify, Apple Music или YouTube не является прямой ссылкой на аудио.

Старые 30-секундные записи не заменяются автоматически, чтобы обновление не затронуло опубликованную историю. Откройте Admin → «История», найдите такую музыку и замените её полным файлом либо удалите запись и добавьте заново через «Добавить» → «Музыка».

## Обновление уже работающего сайта

### Шаг 1. Заменить файлы проекта

Распакуйте архив. Перенесите его содержимое в папку локального репозитория и подтвердите замену файлов. Папки `.git` в архиве нет, поэтому связь вашего локального проекта с GitHub не меняется.

Не удаляйте свои локальные `.env`/`.env.local`, если они уже настроены. В GitHub секретные ключи загружать нельзя.

### Шаг 2. Установить зависимости и проверить сборку

Откройте терминал в папке проекта:

```bash
npm install
npm run build
```

Сборка должна завершиться строкой `built` без ошибок.

### Шаг 3. Применить изменение базы Supabase

```bash
npx supabase@latest login
npx supabase@latest link --project-ref ВАШ_PROJECT_REF
npx supabase@latest db push
```

Команда применит только новую миграцию `0022_global_admin_media_questions.sql`. Данные истории не очищаются.

Если CLI напишет `Remote migration versions not found in local migrations directory`, ничего не помечайте как `reverted` наугад. Выполните:

```bash
npx supabase@latest migration list
```

и сравните список с папкой `supabase/migrations`. В полном архиве есть версии `0000`–`0022`. Если ошибка остаётся, сохраните вывод команды: по нему можно дать точную безопасную команду repair, не рискуя историей миграций.

### Шаг 4. Опубликовать изменённые Edge Functions

Для этого обновления обязательны три команды:

```bash
npx supabase@latest functions deploy process-ai
npx supabase@latest functions deploy ai-director
npx supabase@latest functions deploy reader-interaction
```

Если функции раньше разворачивались не все, безопасно опубликовать полный набор:

```bash
npx supabase@latest functions deploy import-zip
npx supabase@latest functions deploy process-ai
npx supabase@latest functions deploy get-media-url
npx supabase@latest functions deploy public-timeline
npx supabase@latest functions deploy reader-access
npx supabase@latest functions deploy reader-analytics
npx supabase@latest functions deploy reader-reaction
npx supabase@latest functions deploy ai-director
npx supabase@latest functions deploy reader-interaction
```

### Шаг 5. Отправить обновление в GitHub

```bash
git add .
git commit -m "Global mobile admin, AI, GIF, music and questions update"
git push
```

Если Netlify подключён к этому репозиторию, новая публикация начнётся автоматически.

### Шаг 6. Если Netlify не начал публикацию

Откройте Netlify → нужный сайт → **Deploys** → **Trigger deploy** → **Deploy site**.

Настройки остаются прежними:

```text
Build command: npm run build
Publish directory: dist
Node: 20
```

Переменные Netlify также остаются прежними:

```text
VITE_SUPABASE_URL
VITE_SUPABASE_ANON_KEY
```

Не добавляйте в переменные с префиксом `VITE_` ключ `service_role`, OpenRouter-ключ или `READER_ACCESS_SECRET`.

## Проверка после передеплоя

1. Откройте `/admin` с телефона — снизу должны быть «Обзор», «Добавить», «История», «Чтение», «Ещё».
2. В «ИИ» вставьте бесплатный OpenRouter-ключ и нажмите «Обработать новые». Должны появиться счётчики «улучшено» и «без изменений», а не пустой ответ.
3. Добавьте GIF через поиск. После сохранения он должен открыться в Reader. Для старой пустой GIF нажмите «Сохранить GIF надёжно» либо «Загрузить GIF».
4. Добавьте музыку полным файлом. Плеер должен показать настоящую длительность трека, а не 0:30.
5. Добавьте «Сюрприз» → «Вопрос», заполните четыре варианта и ответы.
6. Выберите вариант в Reader, затем откройте Admin → «Чтение» → «Ответы на вопросы».
7. Проверьте запись голосового на HTTPS-адресе Netlify.

## Быстрый откат интерфейса

Перед заменой файлов можно создать отдельную Git-ветку:

```bash
git branch backup-before-0022
```

База меняется только добавочно. Не удаляйте миграцию `0022` после её применения; если захотите вернуть старый интерфейс, достаточно вернуть предыдущий Git-коммит и снова передеплоить Netlify.
