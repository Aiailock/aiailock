# Крупное обновление 0024: карманная книга и надёжные GIF

Обновление превращает Reader в настоящую портретную книгу для телефона и сохраняет прежний способ чтения как второй вариант. Телефон поворачивать не нужно.

## 1. GIF-библиотека больше не бывает пустой

Причина ошибки была в запросе. Wikimedia соединяет поисковые слова по принципу AND: запрос `cute warm hug love` требовал файл, в котором одновременно встречаются все четыре слова, и часто возвращал пустой ответ.

Теперь:

- при открытии сразу показывается встроенная подборка из 16 настоящих GIF с двух независимых CDN;
- коллекция работает без API-ключа;
- есть объятия, сердечки, любовь, спокойная ночь и котики;
- русские запросы превращаются в несколько коротких английских запросов;
- `объятия` ищутся как `hug` и `Movicons hug`, а не как длинная строка;
- четыре коротких поиска выполняются одновременно;
- каждый сетевой запрос ограничен тайм-аутом;
- один неудачный запрос больше не отменяет остальные;
- если поисковый API Wikimedia недоступен, прямые файлы готовой подборки остаются на экране;
- для GIF используется оригинальный анимированный файл, а не неподвижная миниатюра;
- результаты объединяются без дублей;
- выбранная GIF по-прежнему копируется в приватный Supabase Storage перед публикацией.

## 2. Новый режим «Как книгу»

- Каждая запись, фотография, GIF, глава или особый момент становится отдельной экранной страницей.
- Книга работает вертикально на телефоне — поворот экрана не требуется.
- Свайп справа налево открывает следующую страницу.
- Свайп слева направо возвращает предыдущую.
- В правом нижнем углу находится маленькая пиксельная игровая стрелка.
- Слева есть кнопка возврата.
- Показывается номер текущего листа.
- При перелистывании страница сдвигается, слегка поворачивается в 3D и отбрасывает тень.
- Для слабого телефона или включённого reduced motion используется короткое безопасное затухание.
- Пять мягких оттенков подсветки чередуются между листами; собственный фон записи сохраняется.
- Следующая часть длинной истории подгружается заранее, до достижения последнего листа.
- Ошибка подгрузки показывает отдельную кнопку повтора и не закрывает прочитанное.

## 3. Текст не выходит за границы

- Длинные обычные сообщения автоматически делятся на листы примерно по 300 символов.
- Разделение старается закончить лист на абзаце, предложении или слове.
- На продолжениях показывается `лист 1/3`, `лист 2/3` и так далее.
- Реакция показывается только на последнем листе сообщения, а не дублируется.
- Очень большое содержимое фотографии, вопроса или особого момента прокручивается внутри своей страницы и не обрезается.
- Изображения и видео ограничены высотой экрана.
- Добавлены перенос длинных слов, `hyphens`, безопасная ширина и отдельная настройка для экранов до 360 px.
- Нижняя стрелка не перекрывает текст: у страницы есть дополнительная безопасная область.

## 4. Второй режим «Лентой» сохранён и улучшен

- Она сама выбирает на обложке: **«Как книгу»** или **«Лентой»**.
- Выбор запоминается только на её телефоне.
- Режим можно поменять в любой момент через карту путешествия.
- Вертикальная лента теперь тоже состоит из экранных страниц с мягким наклоном/проявлением при входе.
- Закладки, главы, реакции, аналитика прочитанного места, музыка и preview работают в обоих режимах.
- Авточтение остаётся только в вертикальной ленте; в книге оно отключается, чтобы страницы не перелистывались без неё.

## Обновление через телефон

Для команд используйте **GitHub Codespaces**, а не `github.dev`: в `github.dev` можно редактировать файлы, но полноценного терминала нет.

1. Откройте репозиторий GitHub.
2. Нажмите **Code → Codespaces → Create codespace on main**.
3. Загрузите архив в Codespace и распакуйте его содержимое в корень проекта с заменой файлов.
4. Не удаляйте папку `.git`. Не загружайте `.env` или секретные ключи.
5. Выполните:

```bash
git branch backup-before-0024
npm install
npm test
npm run typecheck
npm run lint
npm run build
git status --short
git add .
git commit -m "Pocket book reader and reliable GIF library 0024"
git push
```

## Supabase

Если релиз 0023 уже применён, в 0024 ничего выполнять в Supabase не нужно: новой миграции и Edge Function нет.

Если обновляетесь напрямую с 0022 или старее:

```bash
npx supabase@latest login
npx supabase@latest link --project-ref ВАШ_PROJECT_REF
npx supabase@latest migration list
npx supabase@latest db push
npx supabase@latest functions deploy ai-director
```

Не выполняйте `migration repair` наугад при несовпадении истории. Сначала сохраните вывод `migration list`.

## Netlify

После `git push` Netlify должен начать сборку автоматически.

```text
Build command: npm run build
Publish directory: dist
Node version: 20
```

Если deploy не начался: Netlify → **Deploys → Trigger deploy → Deploy site**.

Переменные остаются прежними:

```text
VITE_SUPABASE_URL
VITE_SUPABASE_ANON_KEY
```

## Проверка после deploy

1. Откройте `/admin` с телефона.
2. Добавьте GIF и откройте библиотеку — первые варианты должны появиться сразу, ещё до поиска.
3. Нажмите «Объятия» и убедитесь, что список не становится пустым.
4. Откройте Reader `/` и на обложке выберите «Как книгу».
5. Перелистните страницу свайпом справа налево и пиксельной стрелкой.
6. Проверьте длинное сообщение: оно должно разбиться на несколько листов.
7. Откройте карту путешествия и переключитесь на «Ленту».
8. Обновите страницу — выбранный режим должен сохраниться.
9. Проверьте фото, GIF, вопрос, реакцию, музыку и переход к главе в книге.

## Откат
