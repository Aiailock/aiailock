# Обновление 0026 — стабильная лента, удобная админка и GIF-поиск

## Что исправлено

- Удалён экспериментальный книжный рендерер, из-за которого Netlify останавливал сборку на `hideReaction`.
- Reader снова работает как одна непрерывная вертикальная лента с подгрузкой следующих частей.
- Удалены неиспользуемые книжные файлы и зависавшие ссылки на старый тест страниц.
- Поиск во вкладке «История» теперь ищет по всей базе, а не только среди элементов открытой страницы.
- Старые страницы истории теперь получают тексты именно своих сообщений, а не только из выборки последних 1200 сообщений.

## Что добавлено в админку

- У каждой записи истории появилась кнопка «Открыть здесь в Reader».
- Reader preview принимает адрес конкретного элемента и после загрузки сразу прокручивает к нему.
- Навигация по страницам истории закреплена сверху и продублирована снизу.
- После перехода «Назад» или «Дальше» админка сама возвращается к началу списка.
- Поиск охватывает исходный и отредактированный текст, воспоминания, заголовки, описания и подписи скриншотов.
- Показаны состояние поиска, число результатов, очистка запроса и понятная ошибка повторной загрузки.
- Во «Воспоминаниях» появились поиск, выбор нескольких записей, массовая важность, массовая анимация и удаление.
- В «Скриншотах» появились поиск, выбор карточек/альбомов, массовые рамки, анимации, позиция, вид альбома и удаление.
- При нажатии «Изменить» у воспоминания или скриншота админка сама прокручивает к форме.

## GIF-поиск

- Русские запросы эмоций разбираются на короткие английские поисковые фразы; добавлены страх, злость, слёзы, радость, шок, неловкость, усталость, извинения и другие состояния.
- Wikimedia теперь получает несколько независимых коротких запросов вместо одной слишком строгой строки.
- Добавлен поиск по полной библиотеке GIPHY через бесплатный developer key.
- При недоступности одного источника остаются результаты другого и встроенная резервная подборка.
- На каждой карточке показывается источник GIF.

Чтобы включить полную библиотеку GIPHY, добавь в Netlify → Site configuration → Environment variables:

```text
VITE_GIPHY_API_KEY=твой_бесплатный_ключ_GIPHY
```

После изменения переменной запусти новый Deploy. Без ключа поиск не пустой: работают Wikimedia Commons и резервная подборка.

## Проверка

Перед публикацией должны успешно проходить:

```bash
npm ci
npm run build
npm run lint
npm test
```

Для этого обновления новые SQL-миграции и повторный `supabase db push` не требуются.
