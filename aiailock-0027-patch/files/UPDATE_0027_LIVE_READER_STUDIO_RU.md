# Обновление 0027 — Live Reader Studio

Это обновление ставится поверх 0026. Новых SQL-миграций нет: существующие данные, порядок истории, фото, GIF, музыка и настройки сохраняются.

## Что изменилось — 20 рабочих функций

1. В защищённом `Reader Preview` у каждой сцены появилась кнопка **«Изменить»**.
2. Текст меняется прямо на отрисованной сцене ещё до сохранения — это настоящее live-preview.
3. Редактор сохраняет данные в правильный источник: `messages`, `memories`, `screenshots` или `timeline_elements`.
4. Прямо в Preview редактируются название, основной текст и дополнительное описание.
5. Там же меняются дата и время сцены.
6. Добавлен выбор настроения сцены.
7. Сцену можно скрыть из публичного Reader без удаления.
8. Можно назначить дату автоматического показа.
9. Оформление, рамка, фон, шрифт, дата, анимация и эффекты редактируются в той же панели.
10. Фото или GIF у воспоминания/скриншота можно заменить прямо в Preview.
11. Для GIF-сцены в Preview доступен поиск по любому текстовому запросу, включая русские эмоции.
12. Есть переходы к предыдущей и следующей сцене без возврата в админ-список.
13. `Ctrl+S` / `Cmd+S` сохраняет сцену, `Esc` закрывает редактор, несохранённые изменения можно вернуть.
14. Ссылка на конкретную сцену копируется одним нажатием.
15. Неопубликованные и запланированные сцены вместе с приватными медиа теперь видны в Admin Preview, но не в публичном Reader.
16. После создания страницы появляется прямая кнопка **«Открыть в Reader и редактировать»**.
17. Бесплатный локальный помощник анализирует текущий текст и предлагает три следующих сцены: GIF, паузу, цитату, альбом, музыку, голосовое, главу, особый момент или интерактив.
18. Предложение не затирает текущий черновик: оно ставится следующим, открывается после сохранения и остаётся неопубликованным до ручного решения.
19. В Reader добавлены поиск по тексту, режим фокуса на текущей сцене и три плотности чтения: плотная, обычная и кинематографичная.
20. Reader получил тонкую вертикальную нить истории, номера сцен, подсветку текущего момента и улучшенное визуальное разделение длинной ленты.

Дополнительно редактор оформления получил 8 готовых стилей и кнопку автоматического подбора по смыслу текста. Для неё не нужны API-ключи или платные запросы.

## Как работает локальный помощник

- Обрабатывает только текст открытого черновика в браузере.
- Распознаёт страх/тревогу, грусть, нежность, юмор, ночь, поездки, праздники, вопросы и воспоминания.
- Для GIF формирует пригодную поисковую фразу.
- Не меняет существующую историю, не удаляет данные и не публикует сцену автоматически.
- Любой результат остаётся редактируемым черновиком.

## Установка

После копирования файлов обновления нужно обязательно обновить две Edge Functions, потому что именно они дают владельцу безопасный доступ к скрытым сценам и их медиа:

```bash
npm ci
npm run build
npm run lint
npm test
npx supabase functions deploy reader-access
npx supabase functions deploy public-timeline
npx supabase functions deploy get-media-url
git add -A
git commit -m "Add live Reader Preview editing and local scene advisor"
git push origin main
```

Netlify после `git push` запускает обычный `npm run build` и публикует `dist`.

## Проверка после установки

1. Войти в `/admin/login`.
2. Создать тестовую страницу и не публиковать её.
3. Нажать «Открыть в Reader и редактировать».
4. Изменить текст и стиль, сохранить через `Ctrl+S`.
5. Перезагрузить Preview и убедиться, что изменения сохранились.
6. Открыть обычный `/` в приватном окне — скрытая сцена не должна быть видна.
7. Ввести в новой GIF-сцене запрос `страх` и проверить результаты поиска.

## Автоматические проверки

- `npm run build` — пройдено.
- `npm run lint` — пройдено.
- `npm test` — пройдено, включая 10 новых проверок контекстного помощника и 4 проверки GIF-поиска.
