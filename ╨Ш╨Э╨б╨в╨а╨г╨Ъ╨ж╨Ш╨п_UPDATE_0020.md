# UPDATE 0020 — Local AI Story Director

Этот архив — полный проект Aiailock с уже встроенным обновлением 0020.

## Что добавлено

- новая вкладка `ИИ-режиссёр` в `/admin`;
- локальный ИИ в браузере администратора через WebLLM/WebGPU;
- режимы `Очень аккуратно`, `Умеренно`, `Кинематографично`;
- анализ уже существующей опубликованной истории;
- предложения пауз, глав, цитат, GIF, картинок, видео, музыки и ссылок;
- бесплатный поиск картинок/GIF/видео через Wikimedia Commons;
- переиспользование существующего поиска музыки;
- AI-предложения сначала сохраняются как черновик;
- скрытый Reader preview виден только авторизованному администратору;
- публикация только после ручного подтверждения;
- существующие сообщения, фото, GIF, музыка и главы автоматически не удаляются и не переписываются.

## Установка после загрузки проекта на компьютер

Открой терминал в корне проекта, где находится `package.json`.

### 1. Установить зависимости

```bash
npm install
```

### 2. Войти в Supabase CLI

```bash
npx supabase@latest login
```

### 3. Связать локальный проект с Supabase

```bash
npx supabase@latest link --project-ref YOUR_PROJECT_REF
```

`YOUR_PROJECT_REF` замени на Project Ref своего проекта Supabase.

### 4. Применить миграцию 0020

```bash
npx supabase@latest db push
```

В списке должна быть миграция:

```text
0020_local_ai_story_director.sql
```

### 5. Обновить Edge Function

```bash
npx supabase@latest functions deploy public-timeline
```

### 6. Проверить сборку

```bash
npm run build
```

Если сборка прошла успешно, проект готов к деплою.

### 7. GitHub / Netlify

Если проект подключён к Netlify через GitHub, загрузи содержимое этого проекта в репозиторий и дождись нового Deploy.

После публикации открой:

```text
https://ТВОЙ-САЙТ/admin
```

и выбери вкладку `ИИ-режиссёр`.

## Первый запуск

1. Открой `ИИ-режиссёр`.
2. Выбери модель `Qwen3 0.6B` для первого теста.
3. Нажми `Загрузить локальный ИИ`.
4. Выбери `Очень аккуратно`.
5. Нажми `Проанализировать всю готовую историю`.
6. Отметь понравившиеся предложения.
7. Для медиа выбери конкретную картинку/GIF/видео/песню.
8. Нажми `Предпросмотр выбранных`.
9. Проверь Reader.
10. Только если всё нравится — `Опубликовать выбранное`.

До последнего шага обычный читатель AI-дополнения не видит.

## Важно

WebLLM не использует OpenAI/Claude/Gemini API. Модель выполняется на устройстве администратора через WebGPU. Первый запуск может скачать модель в кэш браузера. Это интернет-трафик, но не платные AI-запросы.
